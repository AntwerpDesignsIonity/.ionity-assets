# Images

This directory contains general-purpose brand imagery for Ionity Global (Pty) Ltd,
including open graph / social preview images, marketing banners, and backgrounds.

Place image files here following the naming convention:

```
ionity-<purpose>-<variant>.<ext>
```

Examples:
- `ionity-og-default.png` — Default Open Graph preview image (1200×630 px)
- `ionity-banner-hero.jpg` — Hero section marketing banner
- `ionity-bg-dark.svg` — Dark background pattern
